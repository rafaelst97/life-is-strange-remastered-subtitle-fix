# Life is Strange Remastered - Fix Universale dei Sottotitoli

Questa mod risolve il problema critico in cui i sottotitoli scompaiono o mostrano nomi di file interni (es. `Act_E2...`) durante le transizioni di scena o i cambiamenti di episodio in *Life is Strange Remastered*.

## 🌍 Supporto Universale
Questa correzione funziona per **tutte le lingue** disponibili nel gioco (Inglese, Francese, Tedesco, Spagnolo, Italiano, Portoghese e Giapponese). La mod rileva automaticamente la lingua attiva del gioco in tempo reale.

## 🛠️ Come Installare (Installazione Semplice)

1. Scarica ed estrai questo file `.zip`.
2. Vedrai una cartella chiamata `Binaries`.
3. Copia questa cartella `Binaries` e incollala nella directory principale del tuo gioco, dove si trova la cartella principale `LIS`.
   - Il percorso esatto in cui incollare è: `\Life is Strange Remastered\LIS\`
   - Esempio: `C:\Program Files (x86)\Steam\steamapps\common\Life is Strange Remastered\LIS\`
4. Windows ti chiederà se vuoi unire la cartella. Solo il file `XINPUT1_3.dll` verrà posizionato nella cartella `Win64`. NESSUN file originale del gioco verrà sovrascritto o eliminato.

## ⚠️ Disinstallazione
Se desideri rimuovere la mod, cancella semplicemente il file `XINPUT1_3.dll` situato in:
`Life is Strange Remastered\LIS\Binaries\Win64\XINPUT1_3.dll`
