# Life is Strange Remastered - ユニバーサル字幕修正 (Universal Subtitle Fix)

このMODは、シーンの切り替えやエピソードの変更時に字幕が消えたり、内部ファイル名（例：`Act_E2...`）が表示されたりする致命的な問題を解決します。

## 🌍 ユニバーサルサポート
この修正は、ゲーム内で利用可能な**すべての言語**（英語、フランス語、ドイツ語、スペイン語、イタリア語、ポルトガル語、日本語）に対応しています。MODはゲームの設定からリアルタイムでアクティブな言語を自動的に検出します。

## 🛠️ インストール方法（簡単な手順）

1. この `.zip` ファイルをダウンロードして解凍します。
2. `Binaries` という名前のフォルダが表示されます。
3. この `Binaries` フォルダをコピーし、メインの `LIS` フォルダがあるゲームのルートディレクトリに貼り付けます。
   - 貼り付ける正確なパスは次のとおりです： `\Life is Strange Remastered\LIS\`
   - 例： `C:\Program Files (x86)\Steam\steamapps\common\Life is Strange Remastered\LIS\`
4. Windowsがフォルダを統合するかどうか尋ねます。 `XINPUT1_3.dll` ファイルのみが `Win64` フォルダに配置されます。元のゲームファイルが上書きされたり削除されたりすることはありません。

## ⚠️ アンインストール
MODを削除したい場合は、次の場所にある `XINPUT1_3.dll` ファイルを削除するだけです：
`Life is Strange Remastered\LIS\Binaries\Win64\XINPUT1_3.dll`
