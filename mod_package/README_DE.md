# Life is Strange Remastered - Universeller Untertitel-Fix

Dieser Mod behebt das kritische Problem, dass Untertitel verschwinden oder interne Dateinamen anzeigen (z. B. `Act_E2...`), wenn Szenen oder Episoden in *Life is Strange Remastered* gewechselt werden.

## 🌍 Universelle Unterstützung
Dieser Fix funktioniert für **alle im Spiel verfügbaren Sprachen** (Englisch, Französisch, Deutsch, Spanisch, Italienisch, Portugiesisch und Japanisch). Der Mod erkennt die aktive Sprache automatisch und in Echtzeit anhand Ihrer Spieleinstellungen.

## 🛠️ Installation (Einfach)

1. Laden Sie diese `.zip`-Datei herunter und entpacken Sie sie.
2. Sie sehen einen Ordner namens `Binaries`.
3. Kopieren Sie diesen Ordner `Binaries` und fügen Sie ihn in das Hauptverzeichnis Ihres Spiels ein, wo sich der Hauptordner `LIS` befindet.
   - Der genaue Pfad lautet: `\Life is Strange Remastered\LIS\`
   - Beispiel: `C:\Program Files (x86)\Steam\steamapps\common\Life is Strange Remastered\LIS\`
4. Windows wird fragen, ob Sie den Ordner integrieren möchten. Nur die Datei `XINPUT1_3.dll` wird in den Ordner `Win64` kopiert. Es werden KEINE Originaldateien des Spiels überschrieben oder gelöscht.

## ⚠️ Deinstallation
Wenn Sie den Mod entfernen möchten, löschen Sie einfach die Datei `XINPUT1_3.dll` unter:
`Life is Strange Remastered\LIS\Binaries\Win64\XINPUT1_3.dll`
