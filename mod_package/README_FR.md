# Life is Strange Remastered - Correction Universelle des Sous-titres

Ce mod résout le problème critique où les sous-titres disparaissent ou affichent des noms de fichiers internes (ex. `Act_E2...`) pendant les transitions de scènes ou les changements d'épisodes dans *Life is Strange Remastered*.

## 🌍 Support Universel
Cette correction fonctionne pour **toutes les langues** disponibles dans le jeu (Anglais, Français, Allemand, Espagnol, Italien, Portugais et Japonais). Le mod détecte automatiquement la langue active de votre jeu en temps réel.

## 🛠️ Comment Installer (Installation Simple)

1. Téléchargez et extrayez ce fichier `.zip`.
2. Vous verrez un dossier nommé `Binaries`.
3. Copiez ce dossier `Binaries` et collez-le dans le répertoire racine de votre jeu, où se trouve le dossier principal `LIS`.
   - Le chemin exact où vous devez coller est : `\Life is Strange Remastered\LIS\`
   - Exemple : `C:\Program Files (x86)\Steam\steamapps\common\Life is Strange Remastered\LIS\`
4. Windows vous demandera si vous souhaitez fusionner le dossier. Seul le fichier `XINPUT1_3.dll` sera placé dans le dossier `Win64`. AUCUN fichier original du jeu ne sera écrasé ou supprimé.

## ⚠️ Désinstallation
Si vous souhaitez supprimer le mod, supprimez simplement le fichier `XINPUT1_3.dll` situé à :
`Life is Strange Remastered\LIS\Binaries\Win64\XINPUT1_3.dll`
