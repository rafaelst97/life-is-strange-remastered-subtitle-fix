# Life is Strange Remastered - Corrección Universal de Subtítulos

Este mod resuelve el problema crítico donde los subtítulos desaparecen o muestran nombres de archivos internos (ej. `Act_E2...`) durante las transiciones de escenas o cambios de episodios en *Life is Strange Remastered*.

## 🌍 Soporte Universal
Esta corrección funciona para **todos los idiomas** disponibles en el juego (Inglés, Francés, Alemán, Español, Italiano, Portugués y Japonés). El mod detecta automáticamente el idioma activo de su juego en tiempo real.

## 🛠️ Cómo Instalar (Instalación Sencilla)

1. Descargue y extraiga este archivo `.zip`.
2. Verá una carpeta llamada `Binaries`.
3. Copie esta carpeta `Binaries` y péguela en el directorio raíz de su juego, donde se encuentra la carpeta principal `LIS`.
   - La ruta exacta donde debe pegar es: `\Life is Strange Remastered\LIS\`
   - Ejemplo: `C:\Program Files (x86)\Steam\steamapps\common\Life is Strange Remastered\LIS\`
4. Windows le preguntará si desea combinar la carpeta. Solo el archivo `XINPUT1_3.dll` se colocará en la carpeta `Win64`. NO se sobrescribirán ni eliminarán archivos originales del juego.

## ⚠️ Desinstalación
Si desea eliminar el mod, simplemente borre el archivo `XINPUT1_3.dll` ubicado en:
`Life is Strange Remastered\LIS\Binaries\Win64\XINPUT1_3.dll`
